# פרסום Emet לחנות התוספים של כרום

מדריך שלב-אחר-שלב. הכול כבר מוכן בתיקייה - צריך רק לבצע.

## מה כבר מוכן

- ✅ `emet-v1.6.4.zip` - החבילה להעלאה (נבנית עם `./build.sh`)
- ✅ `store/privacy.html` - מדיניות פרטיות (צריך לארח בכתובת ציבורית)
- ✅ `store/STORE_LISTING.md` - כל הטקסטים להעתקה
- ✅ `PRIVACY.md` - גרסת המקור של המדיניות
- ⬜ צילומי מסך - צריך ליצור (ראו למטה)

---

## שלב 1: חשבון מפתח (5 דקות, 5$ חד-פעמי)

1. היכנסו ל-[Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole) עם חשבון Google.
2. שלמו דמי רישום חד-פעמיים של **5$** (מכסה מספר בלתי מוגבל של תוספים, לתמיד).
3. אשרו את הסכם המפתחים.

## שלב 2: אחסון מדיניות הפרטיות (חובה)

חנות התוספים דורשת קישור ציבורי למדיניות פרטיות. הדרך הכי פשוטה - GitHub Pages:

1. פתחו repo ציבורי ב-GitHub (למשל `emet-factcheck`) והעלו את הפרויקט.
2. הפעילו GitHub Pages: Settings → Pages → Source: `main` branch.
3. הכתובת תהיה: `https://<username>.github.io/emet-factcheck/store/privacy.html`

חלופה בלי GitHub: כל אחסון סטטי (Netlify Drop, Vercel, Google Sites) - צריך רק URL שמציג את `privacy.html`.

## שלב 3: צילומי מסך (10 דקות)

צריך 1-5 צילומי מסך בגודל **1280×800** או **640×400** (PNG):

1. פתחו סרטון עברי עם טענות, הפעילו בדיקת עובדות.
2. חכו לכרטיס עם פסיקה מעניינת - עדיף **"לא נכון"** או **"מטעה"** עם קישורי מקורות (זה מדגים את הערך).
3. צלמו מסך (Cmd+Shift+4 במאק), חתכו ל-1280×800.
4. 1-3 תמונות מספיקות. אם תרצו, אפשר להוסיף כיתוב עברי קצר על כל תמונה.

## שלב 4: העלאה ומילוי הטופס (15 דקות)

1. בדשבורד: **New Item** → גררו את `emet-v1.6.4.zip`.
2. **Store listing** - העתיקו מ-`store/STORE_LISTING.md`:
   - Description (התיאור המלא)
   - Category: `News & Weather`
   - Language: `Hebrew`
   - העלו את צילומי המסך
   - האייקון נטען אוטומטית מהחבילה
3. **Privacy practices** - הכי חשוב, כאן בודקים בקפדנות:
   - **Single purpose**: `Real-time fact-checking of Hebrew-language speech in videos and broadcasts.`
   - **Permission justifications**: העתיקו כל אחת מ-`STORE_LISTING.md`
   - **Data usage**: סמנו שהתוסף *אינו* אוסף מידע עבור המפתח; המידע שנשלח לשירותי צד-שלישי הוא לפי בחירת המשתמש, לא נמכר, ומשמש רק לתפקוד. אשרו את שלושת ה-checkboxes.
   - **Privacy policy URL**: הדביקו את הקישור משלב 2.
4. **Save draft** → **Submit for review**.

## שלב 5: המתנה לאישור

- הבדיקה אורכת בדרך כלל **מכמה שעות עד כמה ימים**.
- תוספים עם `tabCapture` (לכידת שמע) עוברים לפעמים בדיקה קפדנית יותר - סיפור הפרטיות הנקי שלנו (אין שרתים, אין איסוף) עוזר מאוד.
- תקבלו מייל כשהתוסף מאושר או אם צריך תיקונים.

---

## טיפ: השקה רכה לפני האישור המלא

רוצים לתת לחברים לנסות *עכשיו*, בזמן שהבדיקה רצה? בהעלאה בחרו **Visibility: Unlisted**:
- כל מי שיש לו את הקישור יכול להתקין בלחיצה, בדיוק כמו תוסף רגיל.
- התוסף לא מופיע בחיפוש בחנות - מושלם למעגל ראשון של משתמשים.
- אחרי שאתם בטוחים, משנים ל-**Public** בלחיצה אחת.

## עדכונים עתידיים

לכל גרסה חדשה: העלו את מספר הגרסה ב-`manifest.json`, הריצו `./build.sh`, והעלו את ה-ZIP החדש באותו Item. משתמשים מקבלים את העדכון אוטומטית.
