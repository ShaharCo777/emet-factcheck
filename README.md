# Emet - בדיקת עובדות בזמן אמת בעברית

תוסף כרום שמאזין לאודיו מהטאב הפעיל, מזהה טענות עובדתיות תוך כדי דיבור, ומציג פסיקות מבוססות-ראיות - בעברית ובזמן אמת. מבוסס על ארכיטקטורת [InTruth](https://github.com/rpanigrahi222/intruth-factcheck), עם התאמה מלאה לעברית.

## מה זה עושה

- **תמלול חי** - לכידת האודיו של הטאב והזרמה ל-Deepgram (מודל **nova-3**, התומך בתמלול עברית בסטרימינג) כולל זיהוי דוברים (diarization).
- **זיהוי טענות** - Claude סורק את התמלול בחלונות מתגלגלים ומחלץ טענות עובדתיות הניתנות לבדיקה (עובדות, סטטיסטיקות, אירועים היסטוריים, הצהרות מדיניות) - ומסנן דעות, תחזיות והכללות.
- **פסיקה מהירה** - כרטיס פסיקה ראשוני מופיע מיד, מבוסס על ידע המודל.
- **אימות מבוסס-ראיות** - כל טענה מאומתת מול חיפוש אינטרנט: במודלי Claude ו-Gemini החיפוש **מובנה במודל עצמו** (Claude web_search / Google Search grounding - בלי מפתח נוסף); במודלי Groq החיפוש רץ דרך Bright Data SERP API. הכרטיס מתעדכן עם קישורים למקורות.
- **שיוך דוברים** - זיהוי דוברים מכותרת הסרטון ("X מול Y", "ראיון עם Z"), אישור ידני של זהות דוברים חדשים, ותיוג כל טענה לדובר שלה.
- **ניתוח לקסיקלי בעברית** - סמני הסתייגות ("אולי", "לדעתי"), ודאות ("תמיד", "בוודאות"), מילות מילוי ("כאילו", "בעצם"), שפה רגשית וגוף ראשון - כאות לביטחון הדובר.
- **דוח ייצוא** - דוח HTML בעברית (RTL) המקובץ לפי דוברים, עם סיכום פסיקות ומקורות.

## סוגי פסיקות

| פסיקה | משמעות |
|---|---|
| נכון | הטענה מדויקת |
| נכון בעיקרו | נכון בעיקרו עם אי-דיוקים קלים |
| לא נכון | הטענה שגויה |
| מטעה | טכנית נכון אך יוצר רושם מוטעה |
| לא ניתן לאימות | אין ראיות מספקות (לא מוצג) |

## התקנה

1. הורידו/שכפלו את התיקייה.
2. פתחו `chrome://extensions` והפעילו **מצב מפתחים**.
3. לחצו **Load unpacked** ובחרו את תיקיית `emet-factcheck`.

## מפתחות API (הביאו-מפתח-משלכם)

בחלון התוסף מזינים:

**ההתקנה הפשוטה ביותר - מפתח אחד בלבד:** מפתח Google AI (בלי כרטיס אשראי) עושה הכול - תמלול, זיהוי טענות, ואימות עם חיפוש Google. נכנסים ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey), מתחברים עם חשבון Google, לוחצים Create API Key, ומדביקים בחלון התוסף. זהו.

| מפתח | חובה? | תפקיד | השגה |
|---|---|---|---|
| Google AI (Gemini) | **מומלץ - מפתח אחד לכול** | תמלול + זיהוי טענות + אימות | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| Deepgram | רשות (שדרוג) | תמלול מקצועי בזמן אמת + זיהוי דוברים | [console.deepgram.com](https://console.deepgram.com/) - ~200$ קרדיט |
| Bright Data | רשות - **רק למודלי Groq** | חיפוש Google לראיות (SERP API) | [brightdata.com](https://brightdata.com/products/serp-api) - 5,000 חיפושים בחודש |

בלי Deepgram, התמלול נעשה עם Gemini במקטעים של כ-15 שניות (לעומת תמלול חי ומיידי עם Deepgram, שכולל גם זיהוי דוברים קולי).

**חיפוש הראיות:** במודלי Claude החיפוש נעשה עם כלי ה-web_search המובנה (כולל חסימת אתרים מוטים בצד השרת; בערך 1 סנט לחיפוש על המפתח שלכם). במודלי Gemini החיפוש נעשה עם Google Search grounding (כלול במכסת ה-free tier). רק במודלי Groq - שאין להם חיפוש מובנה - נדרש מפתח Bright Data; בלעדיו הפסיקות מתבססות על ידע המודל בלבד.

**בחירת מודל שפה** - נדרש מפתח אחד בלבד, לפי המודל שנבחר:

| מודל | עלות | מפתח | הערות |
|---|---|---|---|
| **Gemini 3.5 Flash-Lite (ברירת מחדל)** | **מכסה יומית** | [aistudio.google.com](https://aistudio.google.com/apikey) | מהיר, עם המכסה הגבוהה ביותר - מתאים לזמן אמת |
| Gemini 3.5 Flash | **מכסה יומית** | aistudio.google.com | חכם יותר, מכסה נמוכה יותר |
| Llama 3.3 70B / 3.1 8B (Groq) | **מכסה יומית** | [console.groq.com](https://console.groq.com/keys) | מהיר מאוד; עברית סבירה, פחות מדויק מ-Gemini |
| `claude-haiku-4-5` / `claude-sonnet-5` / `claude-opus-4-8` | בתשלום | [console.anthropic.com](https://console.anthropic.com/) | האיכות הגבוהה ביותר, כולל חסימת אתרים מוטים בחיפוש |

שימו לב: במגבלות הקצב של המודלים, בשידור עמוס טענות ייתכן שחלק מהחלונות ידולגו.

## שימוש

1. פתחו סרטון יוטיוב או שידור חי באתר חדשות ישראלי (mako, ynet, כאן 11, ערוץ 13, ערוץ 14, וואלה).
2. לחצו על אייקון התוסף ואז **התחל בדיקת עובדות**.
3. פאנל צף יופיע עם התמלול החי, הטענות והפסיקות.
4. כשמזוהה דובר חדש - אשרו את זהותו מהכפתורים בבאנר.
5. בסיום - **ייצוא** מוריד דוח HTML מלא.

## ארכיטקטורה

```
אודיו מהטאב ──► offscreen document ──► Deepgram nova-3 (he) ──► תמלול + זיהוי דוברים
                                                                      │
                                          service worker ◄────────────┘
                                          │  חלון 4 משפטים מתגלגל
                                          ├─► מודל: חילוץ טענות + פסיקה מהירה ──► כרטיס "מאמת..."
                                          └─► מודל + חיפוש: פסיקה מבוססת-ראיות ──► עדכון כרטיס + מקורות
                                              (Claude: web_search מובנה | Gemini: grounding | Groq: Bright Data)
```

## פרטיות והרשאות

- `tabCapture` - לכידת אודיו רק לאחר הפעלה ידנית.
- `storage` - שמירת מפתחות מקומית בלבד.
- התמלול נשלח ל-Deepgram; קטעי תמלול נשלחים ל-Anthropic ו-Bright Data לפי המפתחות שהזנתם. שום דבר לא נשלח לשרתים אחרים.

## הסתייגות

בדיקת עובדות אוטומטית אינה מושלמת. פסיקות עלולות להיות שגויות או חלקיות - במיוחד בתמלול אוטומטי של עברית מדוברת. התוסף הוא כלי עזר אינפורמטיבי, לא פוסק מוסמך. בדקו מקורות בעצמכם לפני הסקת מסקנות.
